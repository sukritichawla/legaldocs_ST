# Legal Document Simplifier & Translator

An NLP-powered application for simplifying and translating legal documents using Transformer-based models. The project focuses on making complex legal text easier to understand while supporting translation into Indian regional languages.

## Overview

Legal documents often contain complex terminology and sentence structures that make them difficult for non-specialists to understand. This project explores the use of Natural Language Processing and Transformer models to simplify legal text and make it more accessible.

The project includes both model development/evaluation notebooks and an interactive application for demonstrating the results.

## Features

- Legal document/text simplification
- Multilingual translation
- Transformer-based NLP models
- Support for Indian regional languages
- Interactive application for testing the models
- Model evaluation and experimentation
- Python-based NLP pipeline
